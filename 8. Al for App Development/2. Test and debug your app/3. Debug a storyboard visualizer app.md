## 1. Introduction

Building an app is exciting, but sometimes things do not work as expected.

**Troubleshooting** means finding and solving problems in an app.

Imagine your app is a big puzzle. Instead of fixing everything at once, break it into smaller parts. Check each part to find where the problem is.

For example, if your app should create a video storyboard but shows an error, check the error message and find the cause.

You can then explain the problem to AI and ask it to fix the app.

## 2. Troubleshooting Strategies

Use these steps to find and fix problems:

1. **Break it down:** Divide the app into smaller parts.
2. **Find the problem:** Check which feature is not working.
3. **Check error messages:** Read the error details and debug information.
4. **Explain the issue:** Tell AI what happened and what you expected.
5. **Fix the problem:** Ask AI to update the app.
6. **Test again:** Check if the problem is solved.

This makes troubleshooting easier and more organized.

## 3. Use AI to Improve Your App

AI tools like Gemini can help you update an app.

You can ask AI to:
- Fix errors.
- Improve the user interface (UI).
- Add new features.
- Change how a feature works.
- Follow specific rules.
- Improve the user experience.

You do not need to fix everything in one prompt. Work on one problem at a time.

## 4. Test the Storyboard Visualizer App

A Storyboard Visualizer app turns a video idea into a storyboard.

The storyboard has three main parts:

| Section | What it shows |
|---|---|
| Visuals | What appears on the screen |
| Audio and Dialogue | Voice, sound, and dialogue |
| Shot Type and Duration | Camera shot and how long it lasts |

During testing, check whether the app creates all three sections correctly.

### Common Problems and Fixes

| Problem | Possible Fix |
|---|---|
| App shows a quota error | Check the model's usage limits |
| Storyboard is incomplete | Improve the prompt and output rules |
| Shot duration is too long | Add a rule for shot duration |
| Storyboard ignores video guidelines | Give the app the correct context document |
| Final scene has no CTA | Add a rule that every storyboard must end with a CTA |

## 5. Use Automatic Fixes

You can ask AI to check the generated storyboard and correct problems.

For example:

- Check every shot duration.
- Follow the video guidelines.
- Fix missing storyboard sections.
- Make sure the story follows the user's idea.
- Add a CTA at the end.

A **CTA (Call to Action)** tells viewers what to do next.

Example: "Get started for free."

## 6. Useful Prompt for Troubleshooting

Use this prompt to improve an AI-generated storyboard app:

```text
Act as an experienced app developer and tester.

Review my Storyboard Visualizer app.

Check these areas:
1. User input
2. Storyboard generation
3. Visuals
4. Audio and dialogue
5. Shot type and duration
6. Final Call to Action (CTA)

Find any errors or missing features.

For each problem:
- Explain what is wrong.
- Identify the possible cause.
- Suggest a fix.
- Update the app without removing unrelated features.

Add these rules:
- Every storyboard must have all three sections.
- Follow the provided video guidelines.
- Keep shot durations within the defined limits.
- Always end the storyboard with a clear CTA.

After making changes, tell me what I should test again.
```

## 7. Real-Life Example: Troubleshooting a Security Monitoring App

Imagine you are building a security monitoring app that checks network traffic for possible cyber threats.

During testing, you find some problems:

| Problem | Possible Cause | Possible Fix |
|---|---|---|
| App crashes with large data | Too much data is being processed | Improve data processing |
| Some alerts are missing | Detection rules are incomplete | Review detection rules |
| API requests fail | Usage limit or connection problem | Add error handling |
| Too many false alerts | Detection conditions are too broad | Improve alert conditions |

You can break the app into smaller parts:

1. **Data Collection:** Collect network data.
2. **Threat Detection:** Check the data for suspicious activity.
3. **Alert System:** Notify users about possible threats.

Test each part separately. Use error logs to understand what went wrong.

Then ask AI to help fix the problems and test the app again.

**Important:** This is a learning example. AI-generated fixes must be tested carefully before using a security tool in a real environment.

## 8. Key Notes

- Troubleshooting means finding and solving app problems.
- Break a large problem into smaller parts.
- Use error messages and debug panels to understand problems.
- AI can help update the app's design and features.
- Test the app after every important change.
- Automatic rules can help keep the output consistent.
- Repeated testing and improvement make an app more reliable.

Do not try to fix everything at once. Find one problem, understand it, fix it, and test again.
