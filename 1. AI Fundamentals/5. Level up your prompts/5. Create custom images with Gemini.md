## Introduction

Gemini can help turn ideas into custom images. You can use AI-generated images for:

- Presentations and slides
- Social media posts
- Posters and advertisements
- Educational content
- Professional projects

You can also edit images by giving Gemini clear instructions.

**Before starting:** Sign in to Gemini using your Google Account. Select the Pro model as instructed in the lab.

## Step 1: Brainstorm Image Ideas

First, ask Gemini to suggest creative ideas for your image.

You can create images for different purposes, such as cybersecurity awareness posts, presentation slides, or social media content.

### Example Prompt

```text
I need some ideas for a cybersecurity awareness social media post.

The style should be modern and professional.
The mood should be serious but engaging.

Please give me 3 different creative concepts.
For each concept, provide:

1. Description: Explain the visual layout.
2. Color Palette: Suggest colors that match the mood.
```

### Using a Reference Image

You can upload an image to help Gemini understand your preferred style.

For example, ask Gemini to use the reference image's:

- Composition
- Color scheme
- Overall visual style

**Tip:** A reference image can help Gemini understand what you want more clearly.

Save your favorite concept for the next step.

## Step 2: Draft Text for Your Image

Now, ask Gemini to create text that you can add to your image.

The text may include a headline, short message, subtitle, or call to action.

### Example Prompt

```text
Generate 3 text options for a cybersecurity awareness poster.

The topic is phishing attacks.

For context, the poster will help university students
recognize fake emails and suspicious links.

The tone should be bold and professional.
The main goal is to encourage people to think
before clicking unknown links.

Provide options ranging from short headlines
to more descriptive messages.
```

Choose the text that best matches your image idea.

## Step 3: Generate the Image

Combine your selected visual concept and text to create the final image.

### Example Prompt

```text
Based on the selected cybersecurity awareness concept
and the headline "Think Before You Click",
generate a detailed image.

The image should show a person looking at a suspicious
email on a computer screen.

Use a modern 3D illustration style.

Keep the main subject on the right side.
Leave enough empty space on the left for text.

Use dark blue and red colors.
The overall mood should be serious and professional.
```

**Important:** Give Gemini clear details about the subject, style, layout, colors, and mood.

## Step 4: Edit the Image

The first result may not be perfect. You can ask Gemini to make changes until you get the result you want.

### 1. Change the Composition

Move an object or person to another position.

Example:

```text
Move the main subject to the right side.
Leave more empty space on the left for text.
Keep the same overall design.
```

### 2. Adjust Lighting and Colors

Change the brightness, lighting, or background colors.

Example:

```text
Make the lighting brighter and more natural.
Change the background to dark blue and silver.
Keep the main subject unchanged.
```

### 3. Add or Remove Details

Add new objects or remove unwanted elements.

Example:

```text
Keep the same visual style.
Add a subtle digital network pattern in the background.
Remove the bright light effect.
```

### 4. Change the Visual Style

You can change the image from one style to another.

Example:

```text
Keep the same layout, but change the photographic style
to a clean and modern vector illustration.
```

You can repeat this process and give Gemini more feedback until you are happy with the image.

As a cybersecurity learner, you can use Gemini to create:

| Use Case | Example |
|---|---|
| Security Awareness | Phishing awareness posters |
| Social Media | Cybersecurity tips and learning posts |
| Presentations | Visuals about network security |
| Ethical Hacking | Educational illustrations of attack concepts |

| AI Security | Prompt injection awareness graphics |
| SOC Learning | Security operations workflow diagrams |

## Complete Image Creation Workflow

1. **Brainstorm:** Ask Gemini for creative image concepts.
2. **Write:** Generate headlines and supporting text.
3. **Generate:** Combine your favorite concept and text.
4. **Edit:** Give feedback to improve the image.
5. **Review:** Check the final result before using it.

## Key Takeaways

- Gemini can help create custom images from ideas and text.
- Brainstorming helps you explore different visual concepts.
- Reference images can help explain your preferred style.
- Clear prompts help Gemini understand your requirements.
- You can edit composition, lighting, colors, and details through follow-up prompts.
- AI-generated images should be reviewed before publishing.
