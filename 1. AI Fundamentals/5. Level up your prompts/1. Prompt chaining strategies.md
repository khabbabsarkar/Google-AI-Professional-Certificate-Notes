## Introduction

A good prompt helps AI understand what you want.

A basic prompting framework includes:

- **Persona:** What role should AI play?
- **Task:** What should AI do?
- **Context:** What background information does AI need?
- **Format:** How should AI present the answer?

Now, we will learn two advanced prompting techniques:

1. Powerful Prompt Phrases
2. Prompt Chaining

These techniques help us get better results and manage complex tasks with AI.

## 1. Powerful Prompt Phrases

Powerful prompt phrases are specific words or instructions that guide AI to produce better answers.

There are no magic words that always work. However, clear instructions can help AI understand the task, follow rules, and provide useful details.

### A. Give AI a Process to Follow

Tell AI to complete a task in clear steps.

**Useful phrases:**

- Think step by step.
- First, do this. Second, do that. Finally, complete the task.

**Example:**

> Explain how a basic phishing attack works. First, describe the attack method. Second, explain how attackers trick users. Finally, suggest ways to prevent it.

### B. Define the Audience and Tone

Tell AI who will read the output and what writing style you want.

**Useful phrases:**

- Write this for beginners.
- Use a professional tone.
- Explain it in simple English.

**Example:**

> Explain network security for beginner cybersecurity students. Use simple English and a friendly teaching tone.

### C. Set Clear Rules and Limits

Give AI specific requirements about the output.

**Useful phrases:**

- Write one short paragraph.
- Focus only on the main topic.
- Do not include unrelated information.
- Keep the answer under 200 words.

**Example:**

> Explain SQL injection in one short paragraph. Focus only on how the attack works and do not discuss other web attacks.

### D. Ask AI to Critique Something

Ask AI to review your work and find weaknesses.

**Useful phrases:**

- Critique this from a security analyst's point of view.
- Play devil's advocate.
- What are the weaknesses in this approach?

**Example:**

> Review this incident response plan from the perspective of a cybersecurity analyst. Identify its weaknesses and suggest improvements.

### E. Generate Different Alternatives

Ask AI to provide more than one possible solution.

**Useful phrases:**

- Give me three different versions.
- Suggest an alternative approach.
- Compare these possible solutions.

**Example:**

> Suggest three different ways to improve password security in a small organization. Explain the advantages of each approach.

### F. Expand an Existing Answer

Ask AI to explain a specific point in more detail.

**Useful phrases:**

- Explain point 2 in more detail.
- Give practical examples.
- Add more technical details.
- Explain this for a beginner.

**Example:**

> Explain the second point about multi-factor authentication in more detail. Include a practical cybersecurity example.

## 2. What Is Prompt Chaining?

Prompt chaining means using a series of connected prompts to complete a large task.

Instead of asking AI to do everything in one prompt, you divide the task into smaller steps.

The output from one prompt becomes the input for the next prompt.

### Simple Example

Imagine you want to plan a three-day vacation in Paris.

You can use three connected prompts:

**Prompt 1: Find Places**

> I am going to Paris for three days. I like art, historical places, and parks. Suggest some popular places I can visit.

**Prompt 2: Create an Itinerary**

> Using the places you suggested, create a three-day itinerary. Arrange the places to reduce travel time.

**Prompt 3: Find Restaurants**

> Based on the itinerary, suggest some restaurants near the places I will visit each day.

Each prompt builds on the previous answer.

## 3. How Prompt Chaining Works

<pre>
Prompt 1
    ↓
First Output
    ↓
Prompt 2
    ↓
Second Output
    ↓
Prompt 3
    ↓
Final Result
</pre>

**Main idea:** Break a large task into smaller steps. Connect each step to the next.

## 4. Cybersecurity Example: Prompt Chaining

Imagine you want to create a beginner-friendly cybersecurity learning plan.

You can use prompt chaining in Gemini.

### Prompt 1: Identify Learning Topics

> Act as a cybersecurity career coach. I am a beginner interested in cybersecurity. Suggest five important skills I should learn to prepare for an entry-level cybersecurity role.

### Prompt 2: Create a Learning Roadmap

> Based on the five skills you suggested, create a 30-day learning roadmap. Divide the topics into weekly sections and include practical activities.

### Prompt 3: Find Learning Resources

> Based on the roadmap, suggest free learning resources for each topic. Include beginner-friendly courses, documentation, and hands-on labs.

### Prompt 4: Create a Progress Tracker

> Turn this learning roadmap into a weekly progress tracker. Include the topic, learning activity, expected result, and completion status.

This approach turns a general learning goal into a structured plan.

*Note: Review the suggested resources and check that they are available and suitable before following the plan.*

## 5. Powerful Prompt Phrases vs. Prompt Chaining

| Powerful Prompt Phrases | Prompt Chaining |
|---|---|
| Improve one prompt. | Connect multiple prompts. |
| Add clear instructions and limits. | Break a large task into smaller steps. |
| Guide how AI should respond. | Guide the entire workflow. |
| Useful for improving one answer. | Useful for completing complex projects. |

## 6. Practical Applications

Prompt chaining can help with different types of work.

| Field | Example Workflow |
|---|---|
| Cybersecurity | Identify threats → Analyze risks → Suggest security controls. |
| Marketing | Generate campaign ideas → Create a timeline → Draft content. |
| Sales | Find potential clients → Research their needs → Draft outreach emails. |
| Operations | Identify workflow problems → Analyze causes → Suggest solutions. |
| Education | Select a topic → Create study notes → Generate practice questions. |

## Key Notes

- Powerful prompt phrases make instructions more specific.
- Use clear steps to guide AI through a task.
- Define the audience, tone, and output format.
- Ask AI to critique your work and suggest alternatives.
- Prompt chaining breaks complex tasks into smaller steps.
- The output of one prompt becomes the input for the next.
- Review each output before using it in the next step.
