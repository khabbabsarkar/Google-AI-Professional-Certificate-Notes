## 1. Introduction

Anyone can start using AI tools like Gemini. However, knowing how to write good prompts helps you get better results.

A prompt is an instruction or question that you give to AI.

Good prompting helps AI understand:
- What you want.
- Why you need it.
- How you want the answer.
- What rules it should follow.

In this note, we will learn some useful tips for writing better prompts.

## 2. Follow the Three C's of Prompting

There are three important rules for writing good prompts.

### A. Be Concise

Keep your prompts simple and direct.

Avoid adding too many unnecessary details or asking for many unrelated tasks in one prompt.

**Example:**

Weak prompt:

```text
Tell me everything about cybersecurity, hacking,
networking, AI, and all other technology topics.
```

Better prompt:

```text
Explain the basics of network security
for a beginner. Use simple English
and give three practical examples.
```

### B. Be Clear

Give AI clear and specific instructions.

Avoid vague instructions such as:
- Make it better.
- Explain everything.
- Write something interesting.

Instead, explain exactly what you want.

**Example:**

Weak prompt:

```text
Improve my report.
```

Better prompt:

```text
Review my cybersecurity report.

Correct grammar, improve sentence structure,
and make the explanations easier to understand.

Keep all technical details unchanged.
```

### C. Be Consistent

Use the same words for the same things throughout a conversation.

Changing terms unnecessarily may confuse AI.

**Example:**

If you call a file a "spreadsheet" in your first prompt, continue using the word "spreadsheet" in your follow-up prompts.

Avoid switching between words like:
- Spreadsheet
- Matrix
- Sheet

when you mean the same file.

**Cybersecurity Example:**

If you are discussing a "security incident report," keep using that term instead of changing it to "event document" or "attack file" without a reason.

## 3. Always Evaluate AI Output

AI can make mistakes. So, never use or share its answers without checking them.

After receiving an answer, evaluate it using these four points.

### A. Accuracy

Check whether the information is correct.

Ask yourself:
- Are the facts correct?
- Are the technical details accurate?
- Are the sources reliable?

### B. Bias

Check whether the answer contains unfair opinions or stereotypes.

Ask yourself:
- Does it unfairly favor one group?
- Does it ignore other important perspectives?
- Does it contain stereotypes?

### C. Relevance

Check whether the answer directly matches your request.

Ask yourself:
- Did AI answer my question?
- Is the information useful?
- Did it stay on topic?

### D. Consistency

Check whether the answer follows the same style and instructions throughout.

Ask yourself:
- Is the writing style consistent?
- Does the answer follow the requested format?
- Are there any conflicting statements?

**Cybersecurity Example:**

Imagine you ask AI to explain a suspicious network connection.

Before using its answer, check:
- Accuracy: Does the explanation match the network logs?
- Bias: Is it making unfair assumptions about a user?
- Relevance: Does it explain the connection you asked about?
- Consistency: Does the explanation agree with the evidence?

Remember: An unusual connection does not automatically mean a cyberattack.

## 4. Improve Results Through Iteration

Your first AI response does not always need to be the final answer.

You can improve it by changing your prompt or asking follow-up questions.

Here are four useful techniques.

### A. Revisit Your Prompting Framework

If the result is not useful, improve the four main parts of your prompt:

- Persona: What role should AI take?
- Task: What should AI do?
- Format: How should the answer look?
- Context: What background information does AI need?

### B. Break Complex Tasks into Smaller Parts

Do not ask AI to complete a large and complex task all at once.

Divide it into smaller steps.

**Example: Creating a Cybersecurity Presentation**

1. Ask AI to suggest presentation topics.
2. Ask it to create an outline.
3. Ask it to explain each topic.
4. Ask it to create presentation slides.
5. Ask it to review the final content.

This makes the process easier to manage and review.

### C. Add Constraints

Constraints are rules or limits that guide AI.

For example:

```text
Explain SQL injection.

Requirements:
- Use simple English.
- Keep the answer under 300 words.
- Include one safe example.
- Avoid advanced technical details.
```

Constraints help AI focus on your requirements.

### D. Use References

References are examples or materials that show AI what kind of output you want.

You can provide:
- Text examples.
- Images.
- Documents.
- Audio.
- Videos (if supported by the AI tool).

**Example:**

You provide an old cybersecurity report and ask:

```text
Use the attached report as a reference.

Create a new report about phishing attacks.

Follow the same:
- Writing style.
- Heading structure.
- Formatting.

Do not copy the original report's information.
```

Always explain how the reference should be used.

## 5. Start a New Chat for New Topics

AI uses the previous messages in a conversation to understand your next request.

The amount of information an AI model can use in a conversation is called its **context window**.

If a conversation becomes very long or includes many unrelated topics, the AI may use information that is no longer relevant.

Starting a new chat for a new topic can help keep the conversation focused.

**Example:**

Use separate chats for:
- Learning Python.
- Studying penetration testing.
- Creating LinkedIn posts.
- Understanding AI security.
- Writing course notes.

This helps keep your work organized.

## 6. Create Your Own Prompt Library

A prompt library is a collection of useful prompts that you save and reuse.

Instead of writing the same instructions again and again, you can save your best prompts.

For example, you can create these categories:

| Category | Example Prompts |
|---|---|
| Cybersecurity Learning | Explain technical topics in simple English |
| Penetration Testing | Explain security testing concepts for authorized labs |
| Digital Forensics | Summarize forensic investigation concepts |
| SOC Analysis | Help organize security alerts for review |
| LinkedIn Content | Turn learning notes into engaging posts |
| Report Writing | Review and improve technical reports |

### Example: Reusable Cybersecurity Learning Prompt

```text
Persona:
Act as a cybersecurity instructor.

Task:
Explain the topic I provide.

Context:
I am a beginner learning cybersecurity.

Format:
1. Simple definition.
2. How it works.
3. Real-life example.
4. Cybersecurity use case.
5. Key takeaways.

Requirements:
- Use A2-level English.
- Use short sentences.
- Explain technical terms.
- Keep the explanation easy to understand.
```

You can reuse this prompt whenever you study a new cybersecurity topic.

## 7. A Quick Checklist for Better Prompts

Before sending a prompt, check these points:

- [ ] Is my prompt concise?
- [ ] Are my instructions clear?
- [ ] Am I using consistent terms?
- [ ] Have I provided enough context?
- [ ] Have I explained the expected format?
- [ ] Have I added important constraints?
- [ ] Do I need to provide a reference?

After receiving the answer:

- [ ] Check accuracy.
- [ ] Check for bias.
- [ ] Check relevance.
- [ ] Check consistency.
- [ ] Improve the answer if needed.

## 8. Key Notes

- Follow the three C's: Concise, Clear, and Consistent.
- Always evaluate AI-generated answers.
- Check accuracy, bias, relevance, and consistency.
- Improve results through follow-up prompts.
- Break complex tasks into smaller steps.
- Use constraints to guide AI.
- Provide references when needed.
- Start new chats for unrelated topics.
- Save useful prompts in a prompt library.
