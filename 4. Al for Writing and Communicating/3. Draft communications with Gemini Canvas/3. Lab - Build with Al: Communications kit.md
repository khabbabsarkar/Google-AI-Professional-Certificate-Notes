## Introduction

Gemini can help create different messages for different people using one source document.

In this lab, you will learn how to extract important information from a document, understand stakeholder priorities, and create personalized emails using Gemini Canvas.

A communications kit is a collection of messages prepared for different audiences.

## Lab Requirements

- Sign in to Gemini using your Google Account.
- Prepare a source document.
- Start a new chat with Gemini.
- If you do not have your own document, use the sample launch report from the lab.

## Step 1: Extract Key Points from a Source Document

First, click **New chat** in Gemini.

Attach your source document and explain your role, project, and target audience.

Ask Gemini to find the most important points from the document.

### Example Prompt

```text
I am a cybersecurity project manager responsible
for a new security monitoring system.

I am preparing an email to announce this project
to the company.

Read the attached document and extract
10 important points that I can use in my email.

Focus on:
- Project goals
- Main benefits
- Important activities
- Project timeline
- Expected results

Use clear and simple language.
Do not add information that is not in the document.
```

### What to Do Next

Review the key points generated by Gemini.

Check whether the information is correct and relevant.

You will use these points in the next step.

## Step 2: Identify Stakeholder-Specific Points

Different stakeholders have different priorities.

Ask Gemini to select important points for two stakeholders.

### Example Prompt

```text
Select the most relevant points from the
source document for these two stakeholders:

1. Cybersecurity Manager
2. Finance Manager

First, identify the main priorities of each role.

Then select the most useful points for each person.

For the Cybersecurity Manager, focus on:
- Security improvements
- Risks
- Technical requirements
- Project progress

For the Finance Manager, focus on:
- Budget
- Costs
- Required resources
- Financial risks

Present the results in separate sections.

Do not invent information.
```

### Example Output

| Stakeholder | Important Points |
|---|---|
| Cybersecurity Manager | Security improvements, risks, technical requirements |
| Finance Manager | Budget, costs, resources, financial risks |

Review the selected points before creating the emails.

## Step 3: Draft a Stakeholder Email in Canvas

Now, open the **Tools** menu in Gemini and select **Canvas**.

Use the information from the previous steps to create an email.

### Example Prompt: Cybersecurity Manager

```text
Draft a professional email to the
Cybersecurity Manager.

Use the prioritized points from the previous step.

Include:
- A clear subject line
- A short introduction
- Important project updates as bullet points
- Security benefits and risks
- Required actions or decisions
- A professional closing

Keep the email clear and concise.
Use only information from the source document.
```

Gemini will create the email in Canvas.

You can review and edit the draft directly in the Canvas editor.

## Step 4: Refine the Draft Using Inline Edits

Gemini Canvas allows you to select specific text and request changes.

For example, you can highlight the subject line and ask Gemini to improve it.

### Example Edit Prompts

**Make it shorter:**

```text
Make this email shorter.
Keep all important information.
Remove repeated sentences.
```

**Make it more formal:**

```text
Make this email more formal and professional.
Keep the original meaning.
```

**Improve clarity:**

```text
Rewrite this section using simple and clear English.
Make it easier for the reader to understand.
```

**Improve the subject line:**

```text
Suggest three clear and professional subject lines
for this email.
```

You can repeat Steps 3 and 4 to create another email for the Finance Manager.

## Cybersecurity Example: Complete Communications Kit

Imagine an organization is introducing a new SIEM system.

You need to communicate the project to different stakeholders.

| Audience | Main Communication Focus |
|---|---|
| Cybersecurity Manager | Security goals, risks, and monitoring improvements |
| Finance Manager | Budget, costs, and resources |
| SOC Analysts | Daily workflow and alert handling |
| IT Manager | System integration and technical requirements |
| Senior Management | Business benefits and important decisions |

One source document can support all these messages.

However, each email should highlight the information that matters most to its audience.

## Complete Workflow

1. **Extract:** Upload a source document and find key points.
2. **Prioritize:** Identify what each stakeholder needs to know.
3. **Draft:** Create separate emails using Gemini Canvas.
4. **Refine:** Use inline edits to improve each message.
5. **Review:** Check facts, tone, and audience relevance.
6. **Share:** Send the approved communications to the correct people.

## Important Tips

- Use the latest version of your source document.
- Give Gemini enough information about your role and audience.
- Focus on stakeholder priorities.
- Do not use the same email for every audience.
- Verify facts, dates, names, and numbers.
- Do not include unsupported claims.
- Protect confidential company information.
- Review every message before sending it.

## Key Notes

- Gemini can extract key points from source documents.
- It can identify the priorities of different stakeholders.
- Canvas helps create and edit personalized emails.
- Inline edits make communication improvements faster.
- One source document can support many different messages.
