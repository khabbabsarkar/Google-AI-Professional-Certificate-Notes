## Introduction

Different people need different information.

For example, a finance manager may care about costs, while an operations manager may care about daily tasks and project progress.

Gemini can help create different messages from one source document.

In this lab, Clara from Gemini Marketing shows how to use **Gemini Canvas** to create, edit, and improve messages for different audiences.

## What Will You Learn?

### 1. Stakeholder Alignment

Understand what different people need to know.

Make sure each person receives information that matches their role and priorities.

### 2. Communication Efficiency

Turn one report or document into multiple emails.

This saves time and reduces repeated work.

### 3. Interactive Refinement

Use Gemini Canvas to edit and improve your messages.

You can make changes without starting from the beginning.

## What Is Stakeholder-Based Communication?

A stakeholder is a person or group who has an interest in a project.

Different stakeholders have different goals.

For example:

| Stakeholder | Main Priorities |
|---|---|
| Finance Manager | Budget, cost, and financial risks |
| Operations Manager | Daily work, resources, and deadlines |
| Project Manager | Progress, tasks, and project risks |
| Security Manager | Security risks and protection |
| Senior Management | Business impact and important decisions |

The main idea is simple: one message does not always work for everyone.

## How Does the Lab Work?

The lab uses a corporate report to create emails for two people:

- A finance officer
- An operations manager

The process is:

1. Open Gemini Canvas.
2. Upload or provide the source report.
3. Identify the stakeholders.
4. Understand their priorities.
5. Create a separate email for each stakeholder.
6. Review and edit the messages in Canvas.

## What Is Chain-of-Thought Prompting?

Chain-of-thought prompting is a way of asking AI to work through a task in smaller steps.

For this type of communication task, you can ask Gemini to identify the audience, understand their needs, and then prepare the message.

You do not need to request private internal reasoning. Ask for a brief summary of the audience's priorities and the approach used.

## Cybersecurity Example

Imagine you are preparing an update about a new cybersecurity project.

The project includes:
- A new SIEM system.
- Security monitoring improvements.
- Vulnerability management.
- Staff training.
- A project budget.

You need to send updates to different people.

### Example 1: Email to a Security Manager

The security manager wants to understand security benefits and risks.

```text
Act as a cybersecurity communication specialist.

Review the attached project report.

Identify the main priorities of a cybersecurity manager.

Then write a professional email covering:

1. Security improvements
2. Major risks
3. Important findings
4. Current project progress
5. Decisions or support needed

Use clear and professional language.
Include only information supported by the report.
```

### Example 2: Email to a Finance Manager

The finance manager focuses on money and resources.

```text
Act as a professional business communication assistant.

Review the attached cybersecurity project report.

Write an email for a finance manager.

Focus on:

1. Project budget
2. Expected costs
3. Required resources
4. Financial risks
5. Budget-related decisions

Keep the email short and professional.
Do not invent costs or financial details.
Mark missing information as "Not specified".
```

### Example 3: Email to an Operations Manager

The operations manager needs practical information.

```text
Act as an operations communication specialist.

Review the attached cybersecurity project report.

Write an email for an operations manager.

Focus on:

1. Daily operational changes
2. Project timeline
3. Required resources
4. Team responsibilities
5. Possible operational problems
6. Next steps

Use simple and clear language.
Do not add unsupported information.
```

## Using Gemini Canvas to Refine Messages

After Gemini creates the emails, use Canvas to improve them.

You can ask Gemini to:

- Make an email shorter.
- Use a more professional tone.
- Remove unnecessary details.
- Make the message easier to understand.
- Add important information from the source report.
- Change the message for another audience.

### Example Refinement Prompt

```text
Improve this email for the intended stakeholder.

Make it shorter, clearer, and more professional.

Keep the important facts and original meaning.
Remove repeated information.
Do not add new facts or unsupported claims.
```

## Important Tips

- Understand your audience before writing.
- Use the original document as your source.
- Focus on each stakeholder's priorities.
- Do not send the same message to everyone without reviewing it.
- Check names, numbers, dates, and technical details.
- Protect confidential company information.
- Review every email before sending it.

## Key Notes

- Different stakeholders need different information.
- Gemini can turn one source document into multiple tailored emails.
- Canvas helps create and refine messages interactively.
- Clear communication improves teamwork and decision-making.
- Human review is important before sending any AI-generated message.
