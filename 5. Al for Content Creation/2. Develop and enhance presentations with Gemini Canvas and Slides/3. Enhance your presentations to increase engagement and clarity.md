## 1. Introduction

A good presentation should be clear, simple, and interesting.

Sometimes slides contain too much text or have poor visual design. This makes it difficult for the audience to understand the main message.

Gemini in Google Slides can help improve presentations by refining text, creating custom images, and making the slides look more professional.

## 2. What You Will Learn

In this lab, you will learn how to:

- Improve existing slides.
- Find and highlight important messages.
- Make slide content easier to understand.
- Generate custom images with AI.
- Create images with a consistent visual style.
- Improve the overall design of a presentation.

## 3. Benefits of Using Gemini in Google Slides

| Benefit | Explanation |
|---|---|
| Clearer presentations | Make information easier to read and understand. |
| Visual consistency | Create images with a similar style and design. |
| Saves time | Reduce manual formatting and design work. |
| Better communication | Help the audience understand key messages quickly. |
| Creative freedom | Generate custom visuals without advanced design skills. |

## 4. Improve Your Presentation

Gemini can help turn text-heavy slides into simple and clear slides.

For example, you can ask Gemini to:

- Shorten long paragraphs.
- Highlight important points.
- Improve slide titles.
- Organize information into bullet points.
- Make the language easier to understand.
- Improve the flow of the presentation.

### Example Prompt

```text
Review this presentation and improve its clarity.

Requirements:
- Identify the main message of each slide.
- Replace long paragraphs with short bullet points.
- Use simple and clear language.
- Keep all important information.
- Make the presentation easy to scan.
- Do not change the meaning of the original content.
```

## 5. Generate Custom Images

Images can make presentations more interesting and easier to understand.

Gemini can generate custom images based on your instructions.

You can describe:

- **Style:** 3D, realistic, minimal, modern, or illustrated.
- **Color:** Blue, black, white, or other colors.
- **Subject:** What the image should show.
- **Background:** Where the subject should appear.
- **Purpose:** What message the image should communicate.

### Example Image Prompt

```text
Create a modern cybersecurity illustration
for a professional presentation.

Subject: A cybersecurity analyst monitoring
a security operations center (SOC).

Style: Clean 3D illustration.
Colors: Dark blue, black, and light blue.
Background: Modern security operations center.
Mood: Professional and technology-focused.

Make the image suitable for a presentation slide.
```

## 6. Maintain a Consistent Visual Style

A professional presentation should have a consistent visual style.

For example, using different image styles on every slide can make the presentation look confusing.

To improve consistency:

- Use similar colors across slides.
- Follow one visual theme.
- Use images with similar styles.
- Keep layouts clean.
- Avoid unnecessary decorations.

You can ask Gemini to create multiple images using the same visual style.

### Example Prompt

```text
Create a set of images for a cybersecurity
presentation.

Use the same visual style for every image:
- Modern 3D illustration.
- Dark blue and light blue color palette.
- Clean and professional appearance.
- Simple backgrounds.

Create visuals about:
1. Phishing attacks.
2. Network security.
3. Data protection.
4. Security monitoring.

Keep the style consistent across all images.
```

## 7. Real-Life Cybersecurity Example

### Improve a Cybersecurity Awareness Presentation

Imagine you have prepared a presentation about cybersecurity awareness for university students.

Your slides contain long paragraphs about phishing, passwords, malware, and online safety.

You can use Gemini to improve the presentation.

| Slide | Improvement |
|---|---|
| Phishing | Add an illustration of a suspicious email. |
| Password Security | Show an example of strong password practices. |
| Malware | Add a visual explaining how malware spreads. |
| Network Security | Use a simple network security illustration. |
| Online Safety | Highlight important safety tips with icons or visuals. |

The result is a presentation that is easier to understand and more engaging.

## 8. Best Practices

1. Keep one main message per slide.
2. Use short and simple sentences.
3. Choose images that support the message.
4. Maintain consistent colors and visual styles.
5. Avoid too much text and unnecessary graphics.
6. Review AI-generated images for mistakes.
7. Check all facts before sharing the presentation.

## 9. Key Notes

- Gemini in Google Slides can help improve existing presentations.
- AI can make slide content shorter and clearer.
- Custom images can make presentations more engaging.
- Consistent colors and image styles create a professional look.
- Human review is important for accuracy and quality.

A great presentation does not just contain information. It communicates the right message in a clear and engaging way.
