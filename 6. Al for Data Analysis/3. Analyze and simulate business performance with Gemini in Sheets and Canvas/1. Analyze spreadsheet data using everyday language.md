## 1. Introduction

Data analysis does not always require complex formulas or advanced spreadsheet skills.

Gemini in Google Sheets can help you understand raw data using simple, everyday language.

You can ask Gemini to:
- Analyze spreadsheet data.
- Find important patterns and trends.
- Explain changes in the data.
- Create charts and visualizations.
- Generate short reports.

This helps you turn raw data into useful information for better decisions.

## 2. What You Will Learn

In this lab, you will learn how to:

1. Analyze spreadsheet data using natural language.
2. Find patterns and trends in data.
3. Generate written explanations of your findings.
4. Create charts to present information.
5. Turn raw data into actionable insights.

## 3. What Is Natural Language Data Analysis?

Natural language data analysis means using normal sentences to ask questions about data.

Instead of writing complex spreadsheet formulas, you simply explain what you want to know.

### Traditional Approach

You may need to:
- Write formulas.
- Calculate totals and averages.
- Filter and sort data.
- Create charts manually.
- Explain the results yourself.

### AI-Powered Approach

You can ask Gemini questions such as:

- Which product has the highest sales?
- What trends can you find in this data?
- Which month had the lowest performance?
- Create a chart comparing monthly results.
- Summarize the most important findings.

Gemini can help perform these tasks without requiring you to write complex formulas.

## 4. Step 1: Analyze Spreadsheet Data

First, open your spreadsheet in Google Sheets.

Use Gemini in Sheets to explore the data.

### Example Prompt

Imagine you have a spreadsheet containing monthly sales data.

```text
Analyze this spreadsheet.

Identify:
- Total sales.
- Highest-performing month.
- Lowest-performing month.
- Best-performing product.
- Important trends.

Explain the findings in simple English.

Use only the information available
in the spreadsheet.
Do not invent missing data.
```

Review Gemini's analysis and check whether the results match the original data.

## 5. Step 2: Generate a Written Explanation

Numbers alone may not explain what is happening.

Gemini can turn data into a short narrative that helps people understand the results.

### Example Prompt

```text
Write a short report explaining
the trends in this spreadsheet.

Include:
- Main findings.
- Important changes.
- Positive results.
- Areas that need improvement.
- Possible reasons, clearly marked
  as assumptions when not supported
  by the data.

Use simple and professional English.
```

This can help you prepare reports and presentations more quickly.

## 6. Step 3: Create a Chart

Charts make data easier to understand.

Gemini can help you choose and create a suitable chart.

### Example Prompt

```text
Create a chart showing monthly sales
performance.

Use:
- Month on the horizontal axis.
- Total sales on the vertical axis.
- A clear chart title.
- Easy-to-read labels.

Choose a suitable chart type
and explain what the chart shows.
```

### Common Chart Types

| Chart Type | Best Used For |
|---|---|
| Bar Chart | Comparing different categories. |
| Line Chart | Showing changes over time. |
| Pie Chart | Showing parts of a whole. |
| Column Chart | Comparing values across groups. |
| Scatter Plot | Exploring relationships between two variables. |

Choose a chart based on the type of data and the question you want to answer.

## 7. Cybersecurity Applications

Natural language data analysis can also support cybersecurity work.

### Example 1: SOC Performance Analysis

Imagine you have a spreadsheet containing monthly SOC performance data.

You can ask Gemini to identify:

- Total security alerts.
- Confirmed security incidents.
- Average detection time.
- Average response time.
- False positive rate.
- Monthly changes in alert volume.

**Example Prompt:**

```text
Analyze this SOC performance spreadsheet.

Identify:
- Total security alerts.
- Confirmed incidents.
- Changes in alert volume.
- Detection and response trends.
- Important performance issues.

Create a short summary
and suggest suitable charts.

Do not assume that every alert
represents a confirmed incident.
```

### Example 2: Vulnerability Management

Imagine you have a spreadsheet containing vulnerability records.

You can ask Gemini to:

- Count vulnerabilities by severity.
- Identify systems with the most vulnerabilities.
- Compare resolved and unresolved issues.
- Show remediation trends.
- Create a chart of vulnerability severity.

**Example Prompt:**

```text
Analyze this vulnerability report.

Group vulnerabilities by severity:
Critical, High, Medium, and Low.

Show:
- Total vulnerabilities in each group.
- Resolved vulnerabilities.
- Unresolved vulnerabilities.
- Important findings.

Create a chart showing
the distribution by severity.

Do not invent missing information.
```

### Example 3: Phishing Awareness Survey

You can analyze employee feedback about phishing awareness training.

Ask Gemini to:

- Find common employee concerns.
- Identify knowledge gaps.
- Compare survey ratings.
- Summarize suggestions.
- Create charts to show the results.

These insights can help improve future security awareness programs.

## 9. Responsible AI Practices

Always use AI responsibly when analyzing data.

- Do not include passwords or private information.
- Avoid uploading confidential company data.
- Use approved AI tools for sensitive information.
- Check AI-generated calculations and explanations.
- Verify important findings against the original spreadsheet.
- Do not assume that a trend proves its cause.
- Keep human judgment involved in important decisions.

## 10. Key Notes

- Gemini in Google Sheets can help analyze raw data.
- You can ask questions using everyday language.
- AI can identify patterns, trends, and important findings.
- Gemini can generate written explanations of data.
- Charts make information easier to understand.
- This approach can support sales, project management, customer feedback, and cybersecurity analysis.
- Always verify AI-generated results before making decisions.

Data becomes valuable when we understand what it tells us.

AI can help us move from raw numbers to meaningful insights without spending hours writing complex formulas.
