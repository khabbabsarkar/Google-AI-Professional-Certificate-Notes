## 1. Introduction

Data is not always available in a clean and organized format.

Sometimes, useful information is stored in:
- Images
- PDFs
- Screenshots
- Customer reviews
- Survey responses
- Support tickets

Manually collecting this information can take a lot of time.

Gemini can help extract information from these sources and turn it into structured data. You can then use Google Sheets to organize and analyze it.

## 2. What You Will Learn

In this lab, you will learn how to:

1. Extract information from images using Gemini.
2. Turn unstructured data into an organized spreadsheet.
3. Use the `=AI()` function in Google Sheets.
4. Analyze data using natural language prompts.
5. Find useful patterns and insights from messy data.

## 3. What Is Unstructured Data?

Unstructured data is information that does not follow a fixed table or format.

For example:
- A screenshot containing customer reviews.
- A PDF containing incident reports.
- An image of handwritten records.
- Text written in customer feedback forms.

### Structured vs. Unstructured Data

| Structured Data | Unstructured Data |
|---|---|
| Organized in rows and columns. | Does not follow a fixed format. |
| Easy to sort and filter. | May need cleaning first. |
| Easy to analyze with formulas. | Often needs extraction and organization. |
| Example: Excel spreadsheet. | Example: Screenshot of customer reviews. |

## 4. Step 1: Extract Data from an Image

Gemini can understand images and extract useful information from them.

This is an example of **multimodal prompting**.

Multimodal prompting means giving AI different types of input, such as text and images, to complete a task.

### Example Prompt

Imagine you have an image containing customer reviews.

Upload the image to Gemini and use this prompt:

```text
Extract all customer reviews from this image.

Organize the information into a table
with these columns:

- Customer Name
- Review
- Product
- Rating
- Sentiment

Do not guess missing information.
Use "Not provided" when information
is not available.

Return the result in a clean table.
```

Review the extracted information before using it.

## 5. Step 2: Organize Data in Google Sheets

After extracting information, move the structured data into Google Sheets.

You can use the spreadsheet to:

- Organize information into columns.
- Remove duplicate records.
- Find missing values.
- Sort and filter records.
- Prepare data for analysis.

**Important:** Always check the extracted data. AI may make mistakes when reading unclear images or text.

## 6. Step 3: Analyze Data with the =AI() Function

Google Sheets includes an `=AI()` function that can use natural language instructions to help process information.

Instead of writing complex formulas, you describe what you want in simple English.

### Example

Suppose column B contains customer reviews.

You can use:

```excel
=AI("Classify this review as Positive, Negative, or Neutral", B2)
```

This asks AI to classify the review in cell B2.

Other possible tasks include:

```excel
=AI("Summarize this customer review", B2)
```

```excel
=AI("Identify the main complaint in this review", B2)
```

```excel
=AI("Suggest one improvement based on this review", B2)
```

**Note:** The availability and exact behavior of `=AI()` depend on your Google Sheets account, plan, and feature access. Follow the instructions in the lab for the supported syntax.

## 7. Cybersecurity Applications

These techniques can also help with cybersecurity data analysis.

### Example 1: Analyze Security Incident Reports

Imagine you have incident reports stored in PDF files or screenshots.

You can use Gemini to extract:

- Incident ID
- Incident Type
- Date
- Severity
- Affected System
- Reported Status

Then, organize the information in Google Sheets.

### Example 2: Categorize Security Support Tickets

Suppose a security team receives many support tickets.

You can use AI to classify them into categories:

- Phishing
- Malware
- Account Access
- Password Issues
- Network Problems
- Other

Example prompt:

```text
Read the security support ticket below.

Classify it into one category:

- Phishing
- Malware
- Account Access
- Password Issues
- Network Problems
- Other

Also provide:
- A short summary.
- The possible severity: Low, Medium, or High.

Do not invent information.
```

### Example 3: Analyze Security Alerts

You can organize security alerts and identify patterns.

For example:
- Repeated failed login attempts.
- Unusual login locations.
- Multiple alerts from one system.
- Common types of security events.

AI can help organize and summarize these records. A security analyst must verify the results using original logs and security tools.

## 10. Responsible AI Practices

Before using AI for data analysis:

1. Check the extracted information for errors.
2. Do not share passwords or confidential information.
3. Use approved AI tools for sensitive data.
4. Verify AI-generated categories and summaries.
5. Keep original records for reference.
6. Do not treat AI classifications as final security decisions.

For cybersecurity investigations, preserve original evidence and metadata. Never replace original evidence with AI-generated or modified data.

## 11. Key Notes

- Unstructured data can contain useful information.
- Gemini can extract information from images and other sources.
- Multimodal prompting helps AI understand different types of input.
- Google Sheets can organize and analyze extracted data.
- The `=AI()` function allows natural language instructions for supported tasks.
- AI can save time, but human review is still important.

Data becomes more useful when it is organized and understood. AI can help turn messy information into meaningful insights, giving us more time to focus on analysis and decisions.
