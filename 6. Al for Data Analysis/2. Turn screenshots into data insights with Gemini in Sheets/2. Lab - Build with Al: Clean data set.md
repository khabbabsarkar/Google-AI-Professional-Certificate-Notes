## 1. Introduction

In this lab, you will learn how to use Gemini and Google Sheets to turn unstructured information into an organized dataset.

You will extract information from an image, export it to Google Sheets, and use the `=AI()` function to classify the data.

For example, you can extract customer reviews from a screenshot and classify them as Positive, Neutral, or Negative.

## 2. Lab Requirements

Before starting, make sure you:

- Have a Google Account.
- Can access the Gemini app.
- Can access Google Sheets.
- Are signed in to Gemini and Google Sheets.

## 3. What You Will Learn

1. Extract information from an image.
2. Convert extracted information into a table.
3. Export data from Gemini to Google Sheets.
4. Use the `=AI()` function to classify data.
5. Apply formulas to multiple rows using the fill handle.

## 4. Step 1: Extract and Format Data from an Image

First, open Gemini and click **New chat**.

Upload an image or screenshot that contains the information you want to extract.

For example, you can use an image containing customer reviews.

### Example Prompt

```text
Extract the customer reviews from this screenshot.

Turn them into a table with these columns:

- Customer Name
- Review Date
- Review Text
- Product Name
- Star Rating

Do not guess missing information.
Use "Not provided" when information is missing.

Keep the data organized and accurate.
```

### Export Data to Google Sheets

After Gemini generates the table:

1. Review the extracted information.
2. Click **Export to Sheets**.
3. Open the new Google Sheets file.
4. Check that the data is in the correct columns.

<text weight="medium" color="success" size="sm">Expected result</text>

Your image data is now available as an organized spreadsheet.

## 5. Step 2: Annotate Your Data

Data annotation means adding labels or categories to existing data.

For example, you can classify customer reviews based on their sentiment.

First, create a new column in Google Sheets.

Give it a clear name, such as:

`Customer Sentiment`

Assume the customer review text is stored in cell `B2`.

### Example Formula

```excel
=AI("Analyze this customer feedback and classify it as Positive, Neutral, or Negative", B2)
```

This formula asks Gemini to read the review in B2 and assign a sentiment label.

### More Annotation Examples

**1. Identify the main complaint**

```excel
=AI("Identify the main complaint in this customer review", B2)
```

**2. Classify review topics**

```excel
=AI("Classify this review as Product Quality, Delivery, Customer Service, Price, or Other", B2)
```

**3. Summarize customer feedback**

```excel
=AI("Summarize this customer review in one short sentence", B2)
```

**4. Identify customer satisfaction**

```excel
=AI("Classify the customer's satisfaction as Satisfied, Partially Satisfied, or Unsatisfied", B2)
```

You can create more columns and use different prompts for different types of analysis.

## 6. Step 3: Apply the Formula to All Rows

You do not need to enter the formula manually for every review.

Google Sheets provides a feature called the **fill handle**.

Follow these steps:

1. Enter the `=AI()` formula in the first data cell.
2. Wait for Gemini to generate the result.
3. Select the cell containing the formula.
4. Find the small square at the bottom-right corner of the selected cell.
5. Click and drag it down across the remaining rows.
6. Wait for the results to populate.

This applies the formula to the other rows, using the corresponding review cells.

## 7. Cybersecurity Application

The same workflow can be used to organize cybersecurity information.

Imagine you have a screenshot containing security support tickets.

You can extract the information and classify each ticket.

### Example Dataset

| Ticket ID | Description | Category |
|---|---|---|
| 101 | I received a suspicious email. | Phishing |
| 102 | I cannot access my account. | Account Access |
| 103 | My computer is showing a malware warning. | Malware |
| 104 | I forgot my account password. | Password Issue |

### Example AI Formula

Assume the ticket description is in cell B2.

```excel
=AI("Classify this security ticket as Phishing, Malware, Account Access, Password Issue, or Other", B2)
```

You can also create additional columns for:

- Ticket summary
- Security category
- Possible severity
- Required action

**Important:** AI-generated security categories and severity levels are suggestions. A security analyst must verify them before taking action.

## 9. Important Notes

- Check extracted data before exporting it.
- Make sure the formula references the correct cell.
- Use clear instructions when creating categories.
- Review AI-generated results for mistakes.
- Do not upload confidential customer or security data to unapproved AI tools.
- Keep the original data for comparison and verification.

**Note:** The `=AI()` function requires supported Google Sheets and Gemini access. Availability and usage may depend on your Google account, plan, and feature rollout.

## 10. Key Notes

- Gemini can extract information from images.
- Extracted information can be exported directly to Google Sheets.
- Data annotation adds useful labels to existing information.
- The `=AI()` function can classify and summarize data using natural language.
- The fill handle helps apply formulas to multiple rows.
- This workflow can support customer feedback analysis and cybersecurity ticket management.

AI can reduce the time spent on manual data entry and classification. But clean data and accurate analysis still depend on proper verification.
