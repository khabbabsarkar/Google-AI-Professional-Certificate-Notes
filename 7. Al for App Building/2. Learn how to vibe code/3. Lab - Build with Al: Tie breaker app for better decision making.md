## 1. Introduction

Making decisions can sometimes be difficult, especially when we have multiple options.

AI can help us compare different choices by showing their advantages, disadvantages, risks, and possible benefits.

In this lab, we use **Google AI Studio** and Vibe Coding to build an application called **The Tiebreaker**.

The app helps users make better decisions through different types of analysis.

## 2. What Is The Tiebreaker App?

The Tiebreaker is an AI-powered decision-making application.

Users enter a decision they need to make, and AI analyzes the available options.

The app can provide different types of analysis:

- **Pros and Cons List:** Shows the advantages and disadvantages of each option.
- **Comparison Table:** Compares options side by side.
- **SWOT Analysis:** Examines strengths, weaknesses, opportunities, and threats.

The main goal is to make difficult decisions easier to understand.

## 3. Lab Tasks

### Step 1: Define Your App

First, open Google AI Studio and sign in with your Google Account.

Then:

1. Navigate to **Build AI Apps**.
2. Find the prompt box on the Build page.
3. Describe the application you want to create.
4. Click the **Build** button.

### App Building Prompt

```text
I want an app called The Tiebreaker
that helps me make decisions.

Users should be able to enter
a decision they need to make.

Use AI to analyze the decision
and show different pros and cons.

Provide three analysis options:

1. Pros and Cons List
2. Comparison Table
3. SWOT Analysis

Create a simple and user-friendly
interface.

Add an input field for the decision,
an analysis type selector,
and a Get Analysis button.

Display the AI-generated results
in a clear and organized format.
```

AI Studio will generate the application interface and code.

### Step 2: Test Your Application

After the app is created, test it with a real-world example.

Enter the following decision:

```text
Should I offer my software for free
with paid features, or charge
a flat $20/month premium plan?
```

Then:

1. Find the decision input field.
2. Enter the example decision.
3. Select **Pros and Cons List**.
4. Click **Get Analysis**.
5. Review the generated results.

Check whether the app clearly explains the advantages and disadvantages of both options.

### Step 3: Troubleshoot and Auto-Fix Errors

Sometimes an AI-generated application may contain bugs or stop working.

You do not need to start building the app again.

Google AI Studio provides an **Auto-fix** option for certain errors.

When an error occurs:

1. Check the error message.
2. Look for the **Auto-fix** button in the prompt area.
3. Click **Auto-fix**.
4. Allow AI to analyze the problem.
5. Review the code changes.

AI will attempt to identify the issue and update the code to fix it.

**Important:** Auto-fix may not solve every problem. Always test the application after applying a fix.

### Step 4: Verify the Fix

After Auto-fix is complete, test the application again.

Enter a new decision:

```text
What should I eat tonight:
Sushi or Chinese food?
```

Then:

1. Select **Comparison Table**.
2. Click **Get Analysis**.
3. Review the generated comparison.
4. Check whether the results appear correctly.

This step confirms whether the app can handle a different decision and display another analysis format.

## 4. Example: Cybersecurity Decision Helper

The Tiebreaker concept can also be used in cybersecurity.

Imagine you need to compare two security tools for a small organization.

You could enter:

```text
Should a small organization
use an open-source SIEM solution
or a commercial SIEM platform?
```

Select **Comparison Table**.

The app could compare:

| Criteria | Open-Source SIEM | Commercial SIEM |
|---|---|---|
| Initial Cost | Often lower | Often higher |
| Customization | Usually flexible | Depends on vendor |
| Support | May require community or internal expertise | Vendor support may be available |
| Maintenance | Often managed internally | Depends on the service |
| Scalability | Depends on infrastructure and setup | Depends on the product and plan |

The actual result depends on the selected products, requirements, and available resources.

Other cybersecurity decisions could include:

- Choosing between two cybersecurity certifications.
- Comparing penetration testing tools.
- Selecting a security awareness platform.
- Comparing cloud security solutions.
- Evaluating different incident response strategies.

## 5. Important Features of a Good Tiebreaker App

| Feature | Purpose |
|---|---|
| Decision Input | Allows users to enter a problem. |
| Analysis Selector | Selects the analysis format. |
| AI Analysis | Generates insights about the options. |
| Comparison Table | Displays options side by side. |
| SWOT Analysis | Examines strengths, weaknesses, opportunities, and threats. |
| Results Display | Shows the analysis clearly. |

## 6. Responsible Use

AI-generated recommendations are not always correct.

Before making an important decision:

1. Check the facts.
2. Review the assumptions.
3. Consider missing information.
4. Compare the recommendations with trusted sources.
5. Use your own judgment.

For cybersecurity decisions, never follow an AI recommendation without checking the risks and possible effects.

Avoid entering confidential business information or sensitive security data into unapproved AI tools.

## 7. Key Notes

- Google AI Studio can help build custom applications using natural language.
- The Tiebreaker app supports decision-making.
- It provides Pros and Cons, Comparison Table, and SWOT Analysis.
- AI Studio can help troubleshoot errors through Auto-fix.
- Testing after fixing bugs is important.
- The same app idea can be adapted for cybersecurity decisions.
- AI supports decision-making but should not replace human judgment.

A good decision starts with understanding your options. AI can help organize the information, compare possibilities, and make the decision process easier.
