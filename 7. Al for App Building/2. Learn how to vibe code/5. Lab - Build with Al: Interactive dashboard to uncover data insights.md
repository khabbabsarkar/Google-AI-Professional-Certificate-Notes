## 1. Introduction

Data can contain useful information, but understanding it is not always easy.

AI can help turn raw data into interactive dashboards with charts, graphs, tables, and filters.

In this lab, we use **Google AI Studio** and Vibe Coding to build an interactive dashboard.

The dashboard helps users explore data, identify patterns, and make better decisions.

## 2. What Is an Interactive Dashboard?

An **interactive dashboard** is a visual tool that displays important information in one place.

Users can explore the data by changing filters, selecting categories, and viewing different charts.

Common dashboard elements include:

- **KPI Cards:** Display important numbers and metrics.
- **Pie Charts:** Show parts of a whole.
- **Line Charts:** Show changes over time.
- **Bar Charts:** Compare different categories.
- **Data Tables:** Display detailed information.
- **Filters:** Help users focus on specific data.

## 3. Lab Tasks

### Step 1: Define Your App Prototype

First, open Google AI Studio and sign in with your Google Account.

Then:

1. Navigate to **Build AI Apps**.
2. Find the prompt box on the Build page.
3. Describe the dashboard you want to create.
4. Attach your dataset.
5. You can use the sample data provided in the lab or upload your own.
6. Click the **Build** button.

### Dashboard Building Prompt

```text
I want to create an interactive dashboard
that allows me to visualize data
in different ways.

I will provide a dataset.

Analyze the uploaded data and
create a dashboard using it accurately.

Include suitable visualizations
such as:

- KPI cards
- Pie charts
- Line charts
- Bar charts
- Data tables

Add useful filters so users can
explore specific categories and values.

Make sure the charts and metrics
update when users change the filters.

Use a clean and professional design.

Do not invent data or change
the original values.
```

AI Studio will generate an initial dashboard based on your instructions and uploaded data.

### Step 2: Explore and Filter Your Data

After the dashboard is generated, test its interactive features.

For example:

1. Review the different chart types.
2. Check the KPI cards.
3. Explore the data tables.
4. Use the automatically generated filters.
5. Select a specific product, such as **Premium Tailored Trousers**.
6. Observe how the charts and metrics change.

The main goal is to understand how different filters affect the displayed information.

**Important:** Check that the dashboard uses the correct data and that its calculations match the original dataset.

### Step 3: Iterate on the Design and Layout

You can improve the dashboard's appearance using visual feedback.

Google AI Studio provides an **Annotate app** feature.

Follow these steps:

1. Click **Annotate app** in the prompt box.
2. Use the comment tool to select a specific area.
3. Highlight the element you want to change.
4. Write your design request.
5. Click **OK**.
6. Click **Send prompt**.

The selected area and your feedback will be added to the prompt.

### Example Design Request

Imagine you want to change the appearance of the KPI cards.

```text
Let's make these KPI cards white.

Use a clean design with clear text,
proper spacing, and subtle borders.

Keep the existing data and
calculation logic unchanged.
```

AI will use your visual feedback to update the application code.

You do not need to explain the technical coding details.

## 4. Cybersecurity Example: SOC Interactive Dashboard

The same dashboard idea can be used in cybersecurity.

Imagine you have a sample dataset containing security alerts from a SOC environment.

You can build a dashboard to understand security activity.

### Example Dataset Fields

| Field | Description |
|---|---|
| Alert ID | Unique alert number. |
| Alert Type | Type of security alert. |
| Severity | Critical, High, Medium, or Low. |
| Source IP | IP address linked to the alert. |
| Timestamp | Date and time of the alert. |
| Status | Open, Investigating, or Resolved. |

### Example Dashboard Prompt

```text
Create an interactive SOC dashboard
using the uploaded sample security data.

Include these KPI cards:

- Total Security Alerts
- Critical Alerts
- Open Incidents
- Resolved Incidents

Create these visualizations:

- Pie chart for alert severity.
- Bar chart for alert categories.
- Line chart for alerts over time.
- Table showing individual alerts.

Add filters for:

- Severity
- Alert Type
- Status
- Date

Make sure all charts and KPI cards
update when filters are changed.

Use a professional cybersecurity
dashboard design.

Do not invent security events
or modify the original records.
```

### Possible Dashboard Layout

| Dashboard Element | Purpose |
|---|---|
| Total Alerts | Shows the number of recorded alerts. |
| Critical Alerts | Shows alerts marked as critical. |
| Severity Chart | Displays alerts by severity. |
| Alert Trend | Shows alert activity over time. |
| Status Table | Shows open and resolved alerts. |
| Filters | Helps investigate specific alert groups. |

**Note:** This is a learning example. Use sample or sanitized security data. A dashboard does not prove that an alert is a real attack; analysts must investigate the original evidence.

## 5. Benefits of Interactive Dashboards

- **Better Understanding:** Makes complex data easier to understand.
- **Visual Analysis:** Uses charts and graphs to show patterns.
- **Quick Exploration:** Filters help users find specific information.
- **Time Saving:** Reduces some manual reporting work.
- **Better Decisions:** Helps users understand information before taking action.
- **Customization:** Allows users to change the design and layout.

## 6. Best Practices

1. Use accurate and relevant data.
2. Select charts that match the type of information.
3. Keep the dashboard simple and readable.
4. Use meaningful KPI cards.
5. Test every filter.
6. Verify calculations against the original dataset.
7. Protect confidential information.
8. Review AI-generated code and test the application.

## 7. Key Notes

- Google AI Studio can help build interactive dashboards using natural language.
- AI can turn uploaded datasets into charts, tables, and KPI cards.
- Filters help users explore specific parts of the data.
- Charts can update when filters change.
- Annotate app allows users to provide visual design feedback.
- The same approach can be used for cybersecurity data analysis.
- Always verify data, calculations, and security before using the dashboard.

Data becomes more useful when we can explore it, understand it, and find patterns. AI-powered dashboards make this process easier and help us turn raw data into meaningful insights.
