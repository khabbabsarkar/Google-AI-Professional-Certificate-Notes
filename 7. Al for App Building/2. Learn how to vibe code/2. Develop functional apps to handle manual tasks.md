## 1. Introduction

AI can help us build custom tools and applications without writing all the code manually.

This method is called **Vibe Coding**.

You describe what you want in simple language, and AI helps turn your idea into a working application.

You can act as the idea creator, while AI works as your development assistant.

In this lesson, we explore how to use Google AI Studio to build custom AI tools.

## 2. What Is Vibe Coding?

Vibe Coding is a way to build applications using natural language instructions instead of writing code manually.

You simply tell AI:

- What problem you want to solve.
- What the app should do.
- Which features you need.
- How the app should look.
- How users should interact with it.

AI then generates the code and helps create the application.

You can test the app and ask AI to improve it.

### Simple Example

Imagine you want an app to help you choose between two products.

You can ask AI:

```text
Build a decision-making app.

Allow users to enter two options.

Compare them based on:
- Price
- Quality
- Benefits
- Disadvantages

Show the comparison in a table.
Also provide a final recommendation.

Use a simple and clean design.
```

AI can help build this tool based on your instructions.

## 3. Examples of Custom AI Tools

This lesson introduces three examples of applications that can be built with AI.

### 1. Tiebreaker App

<text>Purpose:</text> Helps users make decisions between different options.

Possible features:
- Compare two or more options.
- Show advantages and disadvantages.
- Calculate costs and benefits.
- Provide a recommendation based on user preferences.

**Example:** Compare two cybersecurity courses based on price, duration, skills, and career value.

### 2. Marketing Materials Generator

<text>Purpose:</text> Helps create marketing content and visual materials.

Possible features:
- Generate advertisement ideas.
- Create social media banners.
- Suggest headlines and captions.
- Generate visual concepts.
- Customize content for different audiences.

**Example:** Create LinkedIn post ideas, cybersecurity awareness banners, and promotional content for a personal cybersecurity brand.

### 3. Interactive Dashboard

<text>Purpose:</text> Displays information in an organized and visual way.

Possible features:
- Show important numbers.
- Display charts and graphs.
- Filter information.
- Update results when data changes.
- Track progress over time.

**Example:** Build a cybersecurity learning dashboard to track completed courses, practical labs, certifications, and study progress.

## 4. Building Custom Apps with Google AI Studio

Google AI Studio is a tool that helps users experiment with AI models and build AI-powered applications.

The course uses AI Studio to demonstrate vibe coding.

### Main Features

| Feature | Purpose |
|---|---|
| Chat | Describe your app idea and give instructions. |
| Build | Create an application from your instructions. |
| Iteration | Improve the app by giving additional prompts. |
| Testing | Check how the application works. |

The basic process is:

1. Open Google AI Studio.
2. Describe the app you want to build.
3. Use the Build feature.
4. Review the generated application.
5. Test its features.
6. Ask AI to make changes.
7. Repeat until the app meets your needs.

*Note: Available features and interface options may change over time.*

## 5. Practical Example: Cybersecurity Incident Decision Helper

Imagine you are learning cybersecurity and want to build a tool that helps compare different responses to a security incident.

You can create a custom application called **Incident Decision Helper**.

### The Problem

During a security incident, there may be several possible actions.

For example:
- Disable a suspicious user account.
- Block a suspicious IP address.
- Isolate an affected device.
- Investigate the activity before taking action.

Each action may have different benefits, risks, and effects.

### Example Prompt

```text
Act as an experienced software developer.

Build a cybersecurity incident
decision helper app.

Allow users to enter:
- Incident type.
- Incident description.
- Available response options.
- Possible risks.
- Expected impact.

Compare the response options
based on:

- Security benefits.
- Possible risks.
- Business impact.
- Required resources.
- Urgency.

Show the comparison in a table.

Allow users to add new options
and update the comparison.

Use a clean and professional
cybersecurity dashboard design.

Clearly explain assumptions
and limitations.

Do not present AI suggestions
as confirmed security decisions.
```

### Possible Features

| Feature | Purpose |
|---|---|
| Incident Input | Enter incident information. |
| Option Comparison | Compare different response actions. |
| Risk Analysis | Display possible risks. |
| Recommendation | Suggest an option based on the provided information. |
| Dashboard | Display results clearly. |

**Important:** This is a learning prototype, not a replacement for professional incident response. Always verify recommendations using trusted security tools, evidence, and established procedures.

## 6. How to Improve an AI-Built App

Your first version may not be perfect.

You can continue improving it with follow-up prompts.

**Change the design:**

```text
Make the app design more modern
and professional.

Use a dark cybersecurity theme
with clear text and simple charts.
```

**Add a feature:**

```text
Add a feature that allows users
to export the comparison report
as a PDF.
```

**Fix an error:**

```text
Review the application and identify
why the comparison feature is not
working correctly.

Fix the issue and explain
what you changed.
```

**Improve usability:**

```text
Make the app easier to use.

Add clear instructions,
input validation, and helpful
error messages.
```

## 7. Responsible AI App Development

AI-generated applications may contain errors or security weaknesses.

Before using an app, remember to:

1. Test all important features.
2. Review the generated code.
3. Check for security vulnerabilities.
4. Protect user information.
5. Validate all inputs.
6. Check how data is stored and processed.
7. Avoid uploading confidential information to unapproved tools.
8. Update and maintain the application.

A working application is not automatically a safe application.

## 8. Key Notes

- Vibe Coding allows us to build apps using natural language.
- AI can generate code and create application interfaces.
- Google AI Studio helps build and test AI-powered applications.
- Tiebreaker apps help compare different options.
- Marketing generators help create promotional materials.
- Interactive dashboards help visualize information.
- Clear prompts and repeated testing improve app quality.
- Human review is important for accuracy and security.

You do not always need to start with programming to build something useful.

Start with a problem, describe your idea, and use AI as your development partner. The real value comes from building tools that solve actual problems.
