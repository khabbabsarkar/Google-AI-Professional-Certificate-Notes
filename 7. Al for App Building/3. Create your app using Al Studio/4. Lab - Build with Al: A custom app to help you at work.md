## Build with AI: A Custom App to Help You at Work

In this lab, you will learn how to build a simple app with **Google AI Studio**.

You do not need to write all the code yourself. You can describe your idea in simple language, and AI Studio will help create the app.

You can also add features, change the design, and share your app with others.

## Before You Start

- Sign in to Google AI Studio with your Google Account.
- Open the **Build** tab.
- Think about a task that takes time in your daily work.
- Choose a task that could become a simple app.

## Optional Step: Find an App Idea

First, identify a task where an app can save time.

Define three things:

1. **Input:** What information will the app receive?
2. **Process:** What will the app do with that information?
3. **Output:** What result will the app create?

Use this simple template:

```text
My app takes [inputs] and does [process]
to create [output] that helps me [goal].
```

### Example: Cybersecurity Incident Report App

```text
My app takes incident details and analyzes
the information to create a structured incident
report that helps me document and understand
security events.
```

### Prompt to Find App Ideas

If you need help, open Gemini at [gemini.google.com](https://gemini.google.com) and try this prompt:

```text
I'm a cybersecurity student.

I often spend time organizing my learning notes,
reviewing security topics, and creating reports.

I want to build a simple app that makes one
of these tasks easier.

The app must be standalone and should not
depend on external databases or systems.

Suggest 3-5 app ideas.

Format each idea using this template:

"My app takes [inputs] and does [process]
to create [output] that helps me [goal]."
```

## Step 1: Describe the App You Want to Build

1. Open Google AI Studio.
2. Go to the **Build** tab.
3. Enter your app idea in the prompt field.
4. Replace the words inside the brackets with your own details.
5. Submit the prompt.

**Example prompt:**

```text
I want to build an app that takes cybersecurity
incident details and analyzes the information
to create a structured incident report that
helps me document security events.
```

AI Studio will create the first version of your app.

When it is ready:

- Review the app.
- Test its features.
- Try it with sample data.
- Check if it works as expected.

## Step 2: Add New Features

After creating the first version, you can improve the app by asking AI Studio to add new features.

Use this prompt:

```text
Add [element] that [purpose].
```

**Example:**

```text
Add a Copy button that copies the complete
incident report so I can paste it into
my notes or documents.
```

You can repeat this process to add more features.

Other possible features:

- Add a Clear button to remove all input.
- Add a Download button to save the report.
- Add a Reset button to start again.
- Add a Search feature to find information.

## Step 3: Change the App's Visual Style

You can also change how your app looks.

Use this prompt:

```text
Change the [visual property] of the app
to use [style description].
```

**Example:**

```text
Change the color scheme of the app
to use dark blue, black, and light grey.

Use a clean and modern cybersecurity dashboard style.

Make the text easy to read and keep the
interface simple.
```

You can ask AI Studio to change:

- Colors
- Fonts
- Buttons
- Layout
- Background
- Dashboard design

## Step 4: Share Your App

When your app is ready, you can publish and share it.

Follow these steps:

1. Click the **Share** button.
2. Find the **Publish your app** option.
3. Turn on the publishing switch.
4. Copy the URL shown on the screen.
5. Share the URL with your teammates.

**Important:** Once published, your app is public. Anyone who can access the published app may be able to use it, depending on its access settings.

Before publishing:

- Test all features.
- Check the app for errors.
- Do not include passwords or sensitive information.
- Review how the app handles user data.
- Make sure you can maintain the app.

## Practical Example: Cybersecurity Learning Assistant

Here is another app idea based on cybersecurity learning.

**App goal:** Help students understand cybersecurity topics and create simple study notes.

| Part | Description |
|---|---|
| Input | A cybersecurity topic or learning text |
| Process | Organize and simplify the information |
| Output | Short notes with key points and definitions |
| Goal | Save study time and improve learning |

### Example prompt

```text
Build a simple Cybersecurity Learning Assistant.

The app should take a cybersecurity topic
or a block of learning text as input.

It should organize the information into:

1. Simple explanation
2. Key points
3. Important terms
4. Real-life examples
5. Short revision notes

Use simple English.

Add buttons to copy and clear the results.

Keep the design clean, modern, and easy to use.
```

## Key Takeaways

Building an app with AI Studio follows four main steps:

1. **Describe:** Explain what you want to build.
2. **Iterate:** Add features and improve the app.
3. **Design:** Change the visual style.
4. **Share:** Publish the app and share its URL.

Remember, you do not need to build everything in one prompt.

Start with a simple idea, test the first version, and improve it step by step.
